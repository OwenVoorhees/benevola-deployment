BENEVOLA — SEEDED DEMO ACCOUNTS
===============================================================================

Every account below is created by the seeders in api/seeders/ and exists only
in your LOCAL development database. They are not real accounts and none of
this is a secret: the whole point is that anyone who clones the project can
log in and see a populated app.

Recreate them at any time from the api/ directory:

    npm run db:fresh        wipe the database, migrate, then seed
    npm run db:seed         seed only (assumes tables already exist)

WHAT TO LOOK AT
===============================================================================

  Sign in as Riverkeepers Alliance to see the organizer side:
    - two posted events, each with a volunteer roster
    - Edit on your own events and profile (these are hidden on other orgs')
    - Post an event, and the delete / close-account controls

  Sign in as any volunteer to see the other side:
    - RSVP and cancel on any event
    - your booked shifts on your profile
    - Edit profile: display name, username, email, profile picture

  Capacity is seeded unevenly on purpose, so the meter and roster are worth
  looking at:

    Weekend Dog Walking            5 / 6      nearly full
    Saturday Meal Packing          5 / 30
    Willamette River Clean-Up      4 / 12
    Riverbank Tree Planting        2 / 20
    After-School Reading Buddies   0 / 15     empty roster state

  Try signing in as one organization and opening another organization's page:
  the edit controls disappear, and the API refuses the change even if you call
  it directly.


NOTES
===============================================================================

  - Sessions are held in Redis when REDIS_URL points at a running server. If
    it does not, the API falls back to an in-memory store and every restart
    logs everyone out. That is expected in local development.

  - Password reset works end to end, but no email is actually sent. In
    development the API returns the reset link in the response, and the
    Forgot Password page shows it to you directly.

  - Seeded images come from picsum.photos and pravatar.cc, so they need an
    internet connection to display. Uploaded images go to Cloudflare R2 when
    the R2_* variables in api/.env are set.
